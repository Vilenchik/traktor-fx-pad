# Traktor FX Pad

XY-контроллер эффектов для **Traktor Pro 3** на Android-телефоне. Телефон подключается к компьютеру по USB
как MIDI-устройство и управляет двумя FX Unit: Dry/Wet, параметрами двух эффектов с XY-пэда,
выбором эффектов и назначением на деки A/B.

Это веб-приложение (PWA): ставится на главный экран из Chrome, работает в полноэкранном режиме и офлайн.
Ничего, кроме браузера, на телефон устанавливать не нужно.

**Открыть:** https://vilenchik.github.io/traktor-fx-pad/

## Возможности

- Два FX Unit на одном экране: рядом в горизонтальной ориентации, друг под другом в вертикальной.
- **XY-пэд**: X управляет параметром первого эффекта, Y — второго.
- **Dry/Wet по касанию**: ползунок задаёт глубину, эффект звучит, пока палец на пэде
  (режим можно переключить на обычный ползунок).
- **↺ 0**: возврат XY в ноль при отпускании, отдельно для каждого юнита.
- Листание эффектов кнопками ‹ ›, включение эффекта тапом по названию.
- Назначение юнита на деку **A** / **B**.
- Названия эффектов синхронизируются с Traktor через обратную MIDI-связь.
- Экран не гаснет во время работы.

## Требования

- Android-телефон с Chrome (Web MIDI API) и USB-кабель с передачей данных.
- Traktor Pro 3 на Windows или macOS.
- FX Unit в Traktor в режиме **Group**.

## Установка

1. Откройте https://vilenchik.github.io/traktor-fx-pad/ в Chrome на телефоне.
2. Меню ⋮ → **Добавить на главный экран**.
3. Подключите телефон к компьютеру и в уведомлении USB выберите режим **MIDI**.
4. Запустите FX Pad и разрешите доступ к MIDI-устройствам.
   Зелёный индикатор и имя порта в верхней строке означают, что подключение есть.

## Настройка Traktor

Preferences → Controller Manager → **Add… → Generic MIDI**.
In-Port и Out-Port — устройство телефона (обычно название модели или «Android»). Канал MIDI — 1.

Команды проще всего назначать через **Learn**: в приложении откройте ⚙ → «MIDI-карта» и нажмите ▶
у нужной строки, отправится только этот CC.

### Входящие команды (телефон → Traktor)

Для команд FX Unit укажите Assignment: FX Unit 1 или FX Unit 2.

| CC Unit 1 | CC Unit 2 | Команда Traktor | Тип / Interaction |
|---:|---:|---|---|
| 20 | 40 | FX Unit → Dry/Wet Adjust | Fader/Knob, Direct |
| 21 | 41 | FX Unit → Knob 1 | Fader/Knob, Direct |
| 22 | 42 | FX Unit → Knob 2 | Fader/Knob, Direct |
| 23 | 43 | FX Unit → Button 1 | Button, Hold |
| 24 | 44 | FX Unit → Button 2 | Button, Hold |
| 25 | 45 | FX Unit → Effect Selector (FX Select 1) | Button, Dec |
| 26 | 46 | FX Unit → Effect Selector (FX Select 1) | Button, Inc |
| 27 | 47 | FX Unit → Effect Selector (FX Select 2) | Button, Dec |
| 28 | 48 | FX Unit → Effect Selector (FX Select 2) | Button, Inc |
| 29 | 49 | Mixer → FX Unit On, Assignment: Deck A | Button, Hold |
| 30 | 50 | Mixer → FX Unit On, Assignment: Deck B | Button, Hold |

### Обратная связь (Traktor → телефон)

Нужна, чтобы на телефоне всегда было то же название эффекта, что и в Traktor,
даже если эффект выбран мышкой.

| CC Unit 1 | CC Unit 2 | Команда Traktor (Add Out) |
|---:|---:|---|
| 32 | 52 | FX Unit → Effect Selector (FX Select 1) |
| 33 | 53 | FX Unit → Effect Selector (FX Select 2) |

Controller Range и MIDI Range оставьте по умолчанию (0–127). Traktor растягивает номер эффекта
на этот диапазон, приложение знает это соответствие для всех 44 эффектов Traktor Pro 3.

Без обратной связи приложение считает выбранный эффект само по нажатиям ‹ ›.
Если название разошлось с Traktor, удержите его и выберите правильное.

## Управление

| Элемент | Действие |
|---|---|
| XY-пэд | X — параметр эффекта 1, Y — параметр эффекта 2 |
| Ползунок D/W | Глубина эффекта (в режиме «по касанию») или Dry/Wet напрямую |
| Название эффекта | Тап — вкл/выкл; удержание — выбрать название вручную |
| ‹ › | Предыдущий / следующий эффект |
| A / B | Назначить юнит на деку |
| ↺ 0 | Возврат XY в ноль при отпускании |
| ⛶ | Полный экран, горизонтальная ориентация |
| ⚙ | MIDI-порты, канал, режимы пэда, MIDI-карта |

## Разработка

Сборки нет: обычные HTML, CSS и JavaScript. Для локального запуска нужен любой статический сервер:

```bash
npx http-server@14.1.1 . -p 8765 -c-1
```

Web MIDI работает только по https или на `localhost`, поэтому на телефоне проверяйте
опубликованную версию. После изменений поднимите номер `CACHE` в `sw.js`,
иначе установленное приложение может показывать старую копию.

GitHub Pages публикует ветку `main` автоматически.

### Структура

| Файл | Назначение |
|---|---|
| `index.html` | Разметка и стили |
| `app.js` | Интерфейс, MIDI, карта CC, список и номера эффектов |
| `sw.js` | Service worker для офлайн-режима |
| `manifest.webmanifest` | Манифест PWA |
| `icon-192.png`, `icon-512.png` | Иконки приложения |

## Ограничения

- Traktor не передаёт по MIDI текст, поэтому названия эффектов зашиты в приложение.
  Если в Traktor изменится набор эффектов, обновите `DEFAULT_FX` и `DEFAULT_NAMES` в `app.js`.
- Проверено на Android + Chrome. iOS не поддерживает Web MIDI в Safari.
